### Objectives

## Workshop structure

- `workshops/livelabs/manifest.json` defines the attendee workshop sequence.
- `workshops/livelabs/index.html` is copied unchanged from the LiveLabs GoldenGate `sample-workshop` sandbox template.
- Each section is maintained in its own Markdown folder and referenced by the manifest.

This repository contains workshop documentation only. Do not add Terraform state, plans, private keys, database wallets, credentials, generated environment files, or the PAF installer.
